# awaitly docs

Documentation site for [awaitly](https://github.com/jagreehal/awaitly), built with Astro and Starlight.

## API reference (generated)

The [API reference](https://jagreehal.github.io/awaitly/reference/api/) is generated from the awaitly package TypeScript source and JSDoc using [TypeDoc](https://typedoc.org/). To regenerate it:

1. From the repo root: `pnpm run generate-api`
2. Or from this directory: `pnpm run generate-api`

This runs TypeDoc to emit JSON (`.typedoc-out/api.json`) and then `scripts/generate-api-from-typedoc.mjs` to produce `src/content/docs/reference/api.md`.

The docs-site build (`pnpm run build`) runs `generate-api` and `generate-rules` before building, so both the API reference and the [rule index](https://jagreehal.github.io/awaitly/rules/) are up to date when you build.

## Rule index (generated)

`src/content/docs/rules/index.mdx` is generated by `scripts/generate-rule-pages.mjs` from the canonical slug spine (runtime error slugs + ESLint rule metadata). Run `pnpm run generate-rules` after changing either.
